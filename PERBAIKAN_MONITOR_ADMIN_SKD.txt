PERBAIKAN MONITOR ADMIN SKD

1. Monitor admin (manajemen.html) sekarang membaca semua ujian berbasis soal-template-core.js, termasuk SKD, TWK, TIU, TKP, BINDO, MTK, PU, WK, Kecerdasan, dan Kepribadian.
2. Untuk SKD TO 6, live monitor menampilkan:
   - nama peserta
   - stage/subtest atau paket ujian
   - file ujian aktif, contoh: skd_to6.html
   - soal aktif
   - total soal
   - jumlah soal terjawab
   - persentase progress
   - sisa waktu
   - preview jawaban yang sudah masuk
3. Jika peserta sudah menjawab semua soal sebelum menekan selesai, monitor menampilkan status:
   "Semua soal sudah dijawab, menunggu submit/selesai."
4. Setelah peserta menekan selesai, data lengkap pindah ke hasil admin/riwayat, bukan lagi di live monitor, karena live monitor hanya untuk aktivitas yang sedang berjalan.
5. Hasil akhir tetap menyimpan review lengkap semua soal di rekap_skor dan hasil_skd.
